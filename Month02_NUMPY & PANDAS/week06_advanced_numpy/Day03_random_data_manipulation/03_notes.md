# Week 6 Day 3

## Random Data
- rand() → Random decimals (0–1)
- randint() → Random integers
- choice() → Random selection
- normal() → Bell-shaped distribution
- seed() → Reproducible output

## Search & Sort
- where() → IF condition
- unique() → Remove duplicates
- sort() → Sort values
- argsort() → Return sorted indices

⭐ Interview Tip
Always use seed() when you want reproducible ML experiments.

⚠ Common Mistake
sort() gives sorted values.
argsort() gives sorted positions.
