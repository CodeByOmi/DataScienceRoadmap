# Week 13 Day 3 — Probability Distributions

Probability distribution:
Shows how probability is distributed across possible values.

Discrete:
Countable values.

Examples:
customers, purchases, defects, dice results.

Continuous:
Measurable values.

Examples:
height, weight, temperature, time.

Uniform distribution:
All possible values have equal probability.

Binomial distribution:
Models number of successes in fixed independent trials.

Binomial conditions:
- fixed number of trials
- two outcomes
- constant probability
- independent trials

Python:
np.random.randint()
np.random.binomial()

Normal distribution:
Bell-shaped distribution.

Mean:
Controls the center.

Standard deviation:
Controls the spread.

Python:
np.random.normal(mean, std, size)

loc → mean
scale → standard deviation
size → number of values
