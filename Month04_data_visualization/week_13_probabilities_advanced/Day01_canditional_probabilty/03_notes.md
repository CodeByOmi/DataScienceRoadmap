# Week 13 Day 1 — Conditional Probability

Conditional probability:
P(A | B) = P(A ∩ B) / P(B)

A ∩ B = A AND B

For sets:
P(A | B) = len(A & B) / len(B)

Independent events:
One event does not affect the other.

Independent:
P(A ∩ B) = P(A) × P(B)

Dependent:
One event changes the probability of another.

Independence test:
P(A ∩ B) == P(A) × P(B)

Python:
A & B       → intersection
len(A)      → number of elements
/           → probability calculation
*           → multiplication
