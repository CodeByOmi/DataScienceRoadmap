# Probability — Day 4

Sample Space = all possible outcomes.

Outcome = one possible result.

Event = collection of outcomes we're interested in.

Probability:
P(A) = favorable outcomes / total outcomes

Probability range:
0 ≤ P(A) ≤ 1

Complement:
P(Aᶜ) = 1 - P(A)

Intersection:
A ∩ B = A AND B
Python: A & B

Union:
A ∪ B = A OR B
Python: A | B

Addition Rule:
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
